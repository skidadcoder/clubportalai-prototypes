# ClubPortalAI Prototypes

Public, clickable prototypes used for product review and staff feedback.

## Organization

- `/` — prototype gallery
- `/parent-portal/` — current Parent Portal prototype for staff review
- `/parent-portal/validation/` — edge-case validation prototype

Add one folder per capability as prototypes are created, for example:

- `/events/`
- `/attendance/`
- `/communications/`
- `/reporting/`

## Rules

- Use sample/fake data only.
- Never publish production IDs, credentials, diagnostics, or real parent/player data.
- The capability folder URL always points to the current prototype under review.
- Use Git history for old versions instead of creating `v1`, `v2`, or `final-final` folders.
- Temporary alternatives may live under paths such as `/parent-portal/option-a/` and `/parent-portal/option-b/`; remove them once a direction is chosen.
- Prototypes are disposable product artifacts, not production application code.

## Feedback

Share the capability URL with staff and collect feedback through the existing review email/process.
