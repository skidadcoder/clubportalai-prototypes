# Midseason Team Offers · Issue #406

Disposable staff-console prototype with synthetic fixtures and in-memory state.

- Review adjusted Dues and four payment schedules: Monthly, 1st & 15th, Every 2 weeks, and Weekly. Pay in Full is a separate published choice.
- Edit one-time Deposit and Season Extras. Single pricing is the default; dual pricing applies to every obligation when enabled.
- Preview one grouped ledger, enrollment payment, fixed sent terms, failure states and staff resend history.
- Business date is January 20, 2027. Reload or Reset demo clears all changes. Nothing is sent, charged or saved to a service.

## Approved UI boundary

This prototype is for the **staff console only**. Issue #409 uses existing Parent Offers & Enrollment screens, controls, navigation and step order to consume fixed offer terms. Parent Portal redesign is outside this prototype. The earlier custom family simulation is excluded from this publication.

This is review evidence, not production application code or a replacement for the acceptance criteria in executable Issues.
