# Group Messaging prototype — #523

Disposable, synthetic UI demonstration. No application API, provider, database, real-user data or credentials. State is held in memory and resets on reload.

Open index.html through a static server or GitHub Pages. Use ?view=staff, ?view=coach, ?view=moderator, or ?view=account; add &device=mobile for the phone preview. Review controls switch synthetic personas/scenarios. Noah demonstrates new-Team-member history.

Owner-final October 10, 2026 decisions govern this version: Official announcement backfill within eligible Team/Program audiences; ordinary conversation history from membership start; Custom rejoining excludes absence; authorized Staff group members can publish corrections; version-specific reads; meaningful viewport viewing; activity order refreshed at list-return boundaries; alerts default off; evidence-based simulated retries. Archive/unarchive is Phase 2 and is absent from the MVP demo.

The 750ms viewing delay is a synthetic approximation, not a prescribed production threshold. Delivery labels and retries are synthetic demonstrations. No alert is sent. The host device switch is review tooling, not production architecture.
